generic-data-extraction contains code for the extraction of the CPRD Aurum data, which is used in project-1-pui-methods and project-2-pui-applied.

project-1-pui-methods contains code for the manuscript "A flexible approach to sequential prediction under intervention". Most recent pre-print available: https://arxiv.org/abs/2602.23943
 
project-2-pui-applied contains code for the manuscript "Predicting cardiovascular risk under intervention: Development and internal validation of the CHARIOT Model in 19 million adults". Currently under review. Most recent pre-print available: https://www.medrxiv.org/content/10.1101/2025.09.18.25336064v2

project-3-rcprd contains code supporting the manuscript: "rcprd: An R package to simplify the extraction and processing of Clinical Practice Research Datalink (CPRD) data, and create analysis-ready datasets". https://doi.org/10.1371/journal.pone.0327229. Also see: https://cran.r-project.org/web/packages/rcprd/index.html, https://github.com/alexpate30/rcprd)
